# 全球交易所图鉴 exchange-atlas

用统一框架横向记录全球主要交易所的交易机制与市场制度——涨跌停、回转交易、结算周期、熔断机制、上市与退市规则等——每条事实标注核实日期与出处，可溯源、可横向对比。

**站点：** https://hrlovefun.github.io/exchange-atlas/

## 这是什么

- **市场机制剖面**：选一个市场，一屏看懂它的交易日怎么运转——交易时段、集合竞价、涨跌停墙、熔断触发线、波动走廊、撮合模型、订单类型、最小报价单位、交收周期、税费，画在「日内时间 × 相对前收价」的平面上，每个元素可点开看原文出处
- 一张对比矩阵：行是交易所，列是可切换的维度组（交易机制/上市退市/清算结算/监管环境/成本税费），横向看出制度异同
- 每家交易所一份档案：按十一章（基本信息、监管、产品、交易机制、上市退市、指数、清算结算、参与者、技术基础设施、成本税费、风险）系统记录
- 每条事实都带来源链接、原文摘录、核实日期与置信度——不是"据说"，是"这份文件的这一条这么写"

## 不覆盖什么

只收录**写进交易所 / 清算所规则、或作为官方数据发布**的制度——交易时段、撮合方式、订单类型与优先规则、最小报价单位、涨跌停与熔断、透明度安排、保证金、错误交易规则、卖空限制、上市与结算规则等，都能在规则手册、公告与官方数据服务里查到。

规则**执行后果**类的要素不在覆盖范围：实际执行风险（订单是否被本地券商转单、机制是否偏向本地参与者）、真实市场冲击与可承受交易量、流动性的真实来源与价差动态、限价申报的价格聚簇行为——这些只能靠小额实盘测试和持续观察积累，本项目不据第三方推断填写（相关字段如 `risks.liquidity_risk_note` 因此结构性地停留在 low/medium 置信度）。
