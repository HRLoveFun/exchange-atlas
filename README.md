# 全球交易所图鉴 exchange-atlas

用统一框架横向记录全球主要交易所的交易机制与市场制度——涨跌停、回转交易、结算周期、熔断机制、上市与退市规则等——每条事实标注核实日期与出处，可溯源、可横向对比。

**站点：** https://hrlovefun.github.io/exchange-atlas/

## 这是什么

- 一张对比矩阵：行是交易所，列是可切换的维度组（交易机制/上市退市/清算结算/监管环境/成本税费），一眼看出制度异同
- 每家交易所一份档案：按十一章（基本信息、监管、产品、交易机制、上市退市、指数、清算结算、参与者、技术基础设施、成本税费、风险）系统记录
- 每条事实都带来源链接、原文摘录、核实日期与置信度——不是"据说"，是"这份文件的这一条这么写"
